### 💡 What is CashWise?

> **"חווה בעיה → למד פתרון → יישם בהצלחה"**

CashWise היא פלטפורמת **למידה חווייתית** שמלמדת ניהול כסף דרך **סימולציות אינטראקטיביות**,  
**קורסים מעשיים**, ו**מנטור AI אישי**. לא עוד תיאוריה יבשה - כאן אתה חי את הסיפור הפיננסי שלך!

## 🔄 The Interactive Learning Loop

```
┌─────────────────────┐
│  🎮 סימולציה       │  ← חווה בעיה פיננסית (ללא קרן חירום)
│  (נסה ולמד)        │
└──────────┬──────────┘
           │
           ▼ טריגר: "💡 רוצה ללמוד איך להתכונן?"
           │
┌──────────────────────┐
│  🎓 אקדמיה          │  ← לומד פתרון (שיעור: קרן חירום)
│  (הבנה עמוקה)       │
└──────────┬───────────┘
           │
           ▼ חזרה עם ידע חדש
           │
┌─────────────────────┐
│  🎮 סימולציה       │  ← מיישם והצלחה! (בונה קרן, עובר משבר)
│  (הצלחה!)          │
└─────────────────────┘
```

### 💡 Example Learning Path

**תרחיש: פוטרת מהעבודה ללא קרן חירום**

1. 😰 **בסימולטור**: משבר - אין כסף לשרוד חודשיים
2. 💡 **טריגר**: "🛡️ רוצה ללמוד על הגנה פיננסית?"
3. 🎓 **באקדמיה**: שיעור על קרן חירום (3-6 חודשים)
4. 💪 **חזרה לסימולטור**: בונה קרן חירום
5. 🎉 **תוצאה**: עובר משבר עתידי בהצלחה + הישג: "מתכנן חכם" 🏆

## ⚡ Quick Start

### 📋 Prerequisites
- ✅ Modern browser (Chrome, Firefox, Edge, Safari)
- ✅ ES6 Modules support
- ✅ Internet connection (Chart.js, GSAP)

### 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/Dan-Ofri/CashWise.git
cd CashWise

# Option 1: Direct open (dev)
start index.html

# Option 2: HTTP Server (recommended)
python -m http.server 8000
# Navigate to: http://localhost:8000
```

### ✅ Verify

Open **Console (F12)** - you should see:
```
╔════════════════════════════════════╗
║  💰 CashWise v7.0 Initialized  ║
╚════════════════════════════════════╝
```
