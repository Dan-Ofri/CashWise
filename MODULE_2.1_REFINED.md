1. הבנת מושג "ריבית דריבית" - הפלא השמיני בתבל

### **Part 2: מה זה ריבית דריבית?** (4 דק')

```
📚 ההגדרה הפשוטה:

"ריבית דריבית = כסף שמרויח כסף על הכסף שהרויח"

🔄 התהליך:
1️⃣ השקעת כסף
2️⃣ הכסף מרויח ריבית
3️⃣ הריבית מצטרפת לכסף המקורי
4️⃣ עכשיו הכסף הגדול יותר מרויח ריבית
5️⃣ חוזר חלילה → צמיחה מתגברת! 🚀

💡 הסוד: ככל שעובר יותר זמן, התהליך מתחזק!

🌳 קונטרסט: השכר vs. העץ
"אם השכר הוא כמו עץ שמניב פירות כל שנה (העלאות),
 אז השקעות הן כמו יער שלם שצומח מהזרעים של העץ הראשון!
 
 🌱 עץ אחד → 🌳 10 עצים → 🌲🌲 100 עצים → 🏞️ יער שלם!
 
 זה ההבדל בין ריבית פשוטה (עץ אחד) 
 לריבית דריבית (יער שמתרבה!)."
```

### **Part 3: הזמן = הכוח שלך!** (3 דק')

```
⏰ למה צעירים הם המנצחים הגדולים?

📊 דוגמה: 3 אנשים מתחילים להשקיע 1,000₪ בחודש ב-10%

┌──────────────────────────────────────────────────────┐

│  💰 השקעה: 1,000₪ × 12 × 30 = 360,000₪             │

"כל שנה שאתה דוחה = עשרות אלפי שקלים שאתה מפסיד!"
"אם אתה צעיר - יש לך את הנכס הכי חשוב: זמן!"
```

```javascript
// מחשבון עם גרף בזמן אמת + טאבים
class CompoundInterestCalculator {
  constructor() {
    // Investment Tab
    this.principal = 10000;
    this.monthlyContribution = 500;
    this.annualReturn = 0.10;
    this.years = 30;
    
    // Salary Tab
    this.currentSalary = 10000;
    this.annualRaise = 0.10;
    
    this.activeTab = 'investment'; // or 'salary'
  }

  calculate() {
    if (this.activeTab === 'investment') {
      return this.calculateInvestment();
    } else {
      return this.calculateSalary();
    }
  }

  calculateInvestment() {
    const months = this.years * 12;
    const monthlyRate = this.annualReturn / 12;
    let balance = this.principal;
    const dataPoints = [];

    for (let month = 0; month <= months; month++) {
      if (month > 0) {
        balance = balance * (1 + monthlyRate) + this.monthlyContribution;
      }
      if (month % 12 === 0) {
        dataPoints.push({
          year: month / 12,
          balance: balance
        });
      }
    }

    return {
      finalBalance: balance,
      totalInvested: this.principal + (this.monthlyContribution * months),
      totalProfit: balance - (this.principal + this.monthlyContribution * months),
      roi: ((balance / (this.principal + this.monthlyContribution * months)) - 1) * 100,
      dataPoints: dataPoints
    };
  }

  calculateSalary() {
    let salary = this.currentSalary;
    const dataPoints = [];
    
    for (let year = 0; year <= this.years; year++) {
      dataPoints.push({
        year: year,
        salary: salary
      });
      
      if (year < this.years) {
        salary = salary * (1 + this.annualRaise);
      }
    }

    const finalSalary = this.currentSalary * Math.pow(1 + this.annualRaise, this.years);
    const lastRaise = finalSalary - (finalSalary / (1 + this.annualRaise));

    return {
      currentSalary: this.currentSalary,
      finalMonthlySalary: finalSalary,
      finalAnnualSalary: finalSalary * 12,
      lastRaise: lastRaise,
      dataPoints: dataPoints
    };
```
